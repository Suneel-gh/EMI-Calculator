Connect FinTrack to your Firebase project

Paste the Web App configuration from Firebase Console → Project settings → General → Your apps. In Firebase Authentication, enable Email/Password. Create a Cloud Firestore database and configure security rules so each signed-in user can access only their own users/{uid} document.

This screen saves Firebase web configuration only. It cannot create a Firebase project or enable Authentication/Firestore for you.
